# Brainstorm Space

A real-time collaborative digital whiteboard for corporate offsites,
brainstorming sessions, and team collaboration.

## Project Overview

Brainstorm Space allows multiple participants to collaborate on a shared
digital whiteboard using drawing tools, sticky notes, text, and shapes.

## Planned Features

- Collaborative whiteboard
- Real-time drawing
- Colored markers and eraser
- Sticky notes
- Text and shapes
- Shared board rooms
- Live participant cursors
- Board persistence
- Export whiteboard as PNG

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Fabric.js
- Node.js
- Express
- Socket.IO
- PostgreSQL
- Prisma
